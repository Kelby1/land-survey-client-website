# Land Survey Client Website — Draft V1

React + Vite concept for a land surveying company website.

## Important before publishing

This is a design/development draft. The client still needs to confirm:

- Official company / legal name
- Logo and brand colors
- Exact surveying services
- Phone, email, office address and service area
- Professional licenses, PRC details, accreditations and memberships
- Equipment actually used by the company
- Team experience and company history
- Project photos / fieldwork photos
- Final privacy / contact-form wording

Do not publish unsupported claims or credentials.

## Run locally

```bash
npm install
npm run dev
```

## Netlify

The quote form is wired for Netlify Forms. `index.html` contains a hidden static form so Netlify can detect the React form at deploy time.

## Stack

- React
- Vite
- CSS only for visual effects
- No database required for V1
